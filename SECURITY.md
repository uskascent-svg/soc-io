# Security policy

SOC-IO is an experimental prototype and is not approved for production or multi-tenant deployment.

- Do not use it as the sole basis for incident response.
- Never submit live secrets, access tokens, private keys, personal data, or sensitive telemetry in public issues.
- Share sanitized reproduction steps, affected commit/version, impact, and redacted logs.
- For sensitive reports, contact the repository owner privately using GitHub's supported security-reporting options.
- Do not test against systems you do not own or have explicit authorization to assess.
